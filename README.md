# LE CROCHET 🧶☕

A modern, elegant web experience and e-commerce platform for handcrafted crochet pieces and specialty coffee.

## 🌐 Live Demo
The application is deployed and live on Vercel:
👉 **[https://le-crochet.vercel.app](https://le-crochet.vercel.app)**

Alternative URL: [https://le-crochet-meselhy2003-4759.vercel.app](https://le-crochet-meselhy2003-4759.vercel.app)

---

## ✨ Features
- **Hero & Video Showcase**: Interactive video hero experience optimized for both desktop and mobile viewports.
- **Curated Collections & Best Items**: Handcrafted crochet items with quick view modals and detailed showcases.
- **Interactive Café Menu**: Specialty coffee offerings with interactive drink cards and details.
- **Cart & Drawer System**: Real-time cart management with custom checkout options.
- **Responsive Design**: Carefully tuned typography and styling for all screen sizes.

---

## 🛠️ Tech Stack
- **Framework**: [React 18](https://react.dev/)
- **Bundler & Dev Server**: [Vite](https://vitejs.dev/)
- **Routing**: [React Router](https://reactrouter.com/)
- **Icons**: [Lucide React](https://lucide.dev/)
- **Deployment**: [Vercel](https://vercel.com/)

## 🚀 Getting Started

### Prerequisites
Make sure you have [Node.js](https://nodejs.org/) installed.

### Installation
```bash
# Clone the repository
git clone https://github.com/meselhy2003-svg/LE-CROCHET.git

# Navigate into the project folder
cd LE-CROCHET

# Install dependencies
npm install

# Start development server
npm run dev
```

### Build for Production
```bash
npm run build
```
